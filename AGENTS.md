# CCAI Repository Guidance

This repository maintains `docs/wiki/` as durable project memory.

For substantive coding, debugging, experiment, or analysis work, read `docs/wiki/index.md` first and then the relevant linked pages. Treat raw code, data, configurations, papers, notes, and run artifacts as evidence; treat the wiki as their maintained synthesis. Persist reusable findings, preserve contradictions and historical changes explicitly, and update the index and append-only log whenever the wiki changes.

Use `$wiki-maintenance` for the detailed initialization, ingest, query, and lint workflow. Keep Git decisions under `$git-workflow`; wiki files are normal task-owned documentation.
